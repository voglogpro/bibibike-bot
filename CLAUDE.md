# CLAUDE.md — навигация по проекту

Инструкции для Claude Code. Цель файла — **не читать `main.py` целиком**.

`main.py` — 12 749 строк, 657 KB (~180K токенов). Полное чтение стоит около $0.9 за раз
и почти всегда лишнее. Ниже карта: находи нужную секцию по таблице и читай
только её через `Read` с `offset`/`limit`.

Общее описание системы, переменные окружения и деплой — в `README.md`.
Здесь только то, что нужно для правок.

## Конвенции

**Именование.** HTTP-хендлеры — `api_*` (`api_shift_start`, `api_crm_tasks`).
Внутренние помощники — с подчёркивания (`_crm_city`, `_shift_worked_min`).
Фоновые воркеры — `*_worker` + одноразовая операция `*_once`, чтобы её можно
было вызвать из тестов.

**Асинхронность.** Всё I/O — `async`, БД через `aiosqlite`. Соединение —
`db_connect()`. Стек: `aiogram 3.13`, `aiohttp 3.10`, `aiosqlite 0.20`.

**Секции.** Новую функцию клади в свою секцию, а не в конец файла. Маркеры
`[NN-NAME]` — единственный способ навигации по файлу, их нельзя ломать.

**Миграции БД.** Только добавление таблиц и колонок внутри `init_db()`.
Существующие данные не удаляются и не пересоздаются: у бота живая база
на проде, откатить её нельзя.

**Часовые пояса.** Города в разных зонах, время считается через `_city_tz(city)`
и `pytz`. Не используй наивный `datetime.now()` в логике смен.

**Язык.** Комментарии, сообщения бота и тексты интерфейса — на русском.

## Что нельзя

- удалять или переименовывать секционные маркеры `[NN-NAME]`;
- коммитить `.env`, `*.db`, фотографии сотрудников, токены и пароли
  (`.gitignore` это закрывает — не обходи его через `git add -f`);
- ломать обратную совместимость схемы БД;
- запускать бота локально с рабочим `BOT_TOKEN`, пока прод работает —
  два polling-экземпляра на одном токене конфликтуют.

## Проверки перед коммитом

Минимум — компиляция и регрессия парсера:

```powershell
python -m py_compile main.py
python tests\regression_check.py
```

Если трогал CRM, добавь:

```powershell
python tests\crm_backend_check.py
python tests\crm_automation_check.py
```

Полный список — в `README.md`, раздел «Проверки перед релизом».
Тесты работают на временной базе и прод не трогают.

## Релиз

`BUILD_VERSION` (строка 252) — версия сборки, видна в `/health`. Обновляй её
при заметных изменениях: по ней проверяют, что BotHost пересобрал коммит.

Деплой автоматический с ветки `main`, отдельного шага публикации нет —
пуш в `main` уходит на прод.

## Как экономить контекст в этом репозитории

1. Не читай `main.py` целиком — только нужную секцию по таблице выше.
2. Ищи через `Grep` по имени функции, потом читай вокруг найденной строки.
3. Одна задача — одна сессия: длинный диалог переотправляет всю историю.
4. Правки в `main.py` делай через `Edit`, не переписывай файл целиком
   (`Write` на 657 KB — это впустую потраченные деньги и риск потерять код).
